# Dahası Var! — Tasarım alternatifleri

Kapadokya Üniversitesi kampanyası için altı statik tasarım. Her tasarım Yandal, Mikro Yeterlilik, SEM ve KÜN Kariyer seçeneklerini içerir.

## Yayın

GitHub Pages: https://yavuzhanis.github.io/dahasi-var-tasarimlar-html/

`index.html` tasarım karşılaştırma sayfasıdır. `alternatif-1.html` ile `alternatif-6.html` arasındaki dosyalar tasarımları açar. `-yandal`, `-mikro`, `-sem` ve `-kariyer` sürümleri ilgili seçeneği başlangıçta gösterir.

`main` dalına gönderilen değişiklikler `.github/workflows/pages.yml` üzerinden otomatik yayımlanır. Derleme veya bağımlılık kurulumu gerekmez.

## Yerel kullanım

```sh
python3 -m http.server 8091
```

http://localhost:8091 adresini açın.

## İçerik

KÜN Kariyer bağlantıları https://kariyer.kapadokya.edu.tr/ adresine gider. Kariyer tanıtım metinleri sonradan düzenlenebilecek başlangıç içeriğidir. Görsel kaynakları ve sunum bilgileri `SUNUM-BILGISI.txt` dosyasındadır.

Bu bir tasarım sunumudur; sayfalardaki `noindex` işaretleri ve taramayı engelleyen `robots.txt` korunmuştur.
